# Netflix_Data_Analysis

## About the Project

This project is a simple data analysis of the Netflix Movies and TV Shows dataset using **Python**, **Pandas**, and **NumPy**. The main goal was to practice data cleaning, data exploration, and extracting useful insights from a real-world dataset.

Instead of focusing on visualizations, this project concentrates on understanding the data, cleaning missing values, and answering different business-related questions using Python.

---

## Dataset

The dataset contains information about Netflix movies and TV shows, including:

* Title
* Type (Movie or TV Show)
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre
* Description

---

## Tools Used

* Python

---

## Project Workflow

The project was completed in the following steps:

1. Loaded the dataset.
2. Explored the dataset structure.
3. Checked missing values and duplicate records.
4. Cleaned the dataset.
5. Converted date columns into proper datetime format.
6. Created additional columns such as Year Added, Month Added, and Duration.
7. Performed exploratory data analysis.
8. Saved the cleaned dataset and analysis results.

---

## Questions Answered

Some of the questions explored in this project include:

* How many Movies and TV Shows are available?
* Which countries have the most Netflix content?
* Who are the top directors?
* Which actors appear most frequently?
* What are the most common genres?
* What ratings are most common?
* Which year had the highest number of releases?
* Which month does Netflix add the most content?
* What is the average movie duration?
* Which is the longest and shortest movie?
* How much content is available from India?

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/Muhammad-Nafeah/Netflix_Data_Analysis.git
```

2. Open the project folder.

3. Install the required libraries.

```bash
pip install -r requirements.txt
```

4. Run the project.

```bash
python netflix_analysis.py
```
